OAuth setup & manual token

  1. In Salesforce Setup, create an External Client App or open an existing compatible app and enable OAuth.
  2. Copy the callback URL above into the app’s callback URL field. Enable the Manage user data via APIs (api) scope.
  3. Enable Require Proof Key for Code Exchange (PKCE) and disable Require Secret for Web Server Flow. No client secret is needed.
  4. Allow your user to access the app. If administrator approval is required, assign access through a profile or permission set. Save the app settings.
  5. Paste the app’s Consumer Key (Client ID) above, confirm your instance URL, and click Connect Salesforce. Complete sign-in and consent.
  6. Enter your Claude API key below and click Save settings. Once Salesforce API access is verified, choose or load a flow.
